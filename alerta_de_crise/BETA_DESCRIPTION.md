# SignalFlow Beta

SignalFlow é um app experimental para acompanhar sinais fisiológicos durante sessões guiadas. Ele usa HealthKit, quando autorizado, para ler frequência cardíaca e HRV disponíveis, além de manter uma fonte de simulação para testes.

A versão beta inclui protocolos guiados de repouso, ativação leve, recuperação e feedback subjetivo, com exportação CSV e análises simples de coleta. A coleta HealthKit ocorre somente com o app aberto.

SignalFlow não realiza diagnóstico, não prevê crises e não substitui atendimento profissional.
