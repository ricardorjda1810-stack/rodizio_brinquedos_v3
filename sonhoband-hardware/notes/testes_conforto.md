# Testes de conforto

Checklist inicial para validar prototipos fisicos do SonhoBand em TPU antes de evoluir para molde de silicone.

## Checklist

- [ ] Conforto geral durante uso curto.
- [ ] Conforto geral durante uso prolongado supervisionado.
- [ ] Tamanho adequado para pulso infantil.
- [ ] Tamanho adequado para tornozelo infantil.
- [ ] Ausencia de cantos rigidos ou pontos de pressao.
- [ ] Pressao da cinta adequada, sem apertar demais.
- [ ] Pressao da cinta suficiente para manter a caixa estavel.
- [ ] Passagem do elastico pelas fendas sem rasgar, travar ou dobrar demais.
- [ ] Elastico nao escorrega nas fendas durante movimento.
- [ ] Estabilidade no pulso com movimentos leves.
- [ ] Estabilidade no tornozelo com movimentos leves.
- [ ] Area fina do sensor encosta de forma consistente na pele.
- [ ] Area fina do sensor nao gera marca, dor ou incomodo.
- [ ] Corpo nao gira excessivamente durante o uso.
- [ ] Corpo nao levanta nas laterais durante o uso.
- [ ] Risco de incomodo identificado e documentado.
- [ ] Ajustes necessarios anotados para a proxima versao.
